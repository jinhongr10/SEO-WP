# macOS 折叠侧栏窗口按钮修复设计

## 背景

Electron 桌面端使用 `hiddenInset` 标题栏，并通过 `trafficLightPosition` 自定义 macOS 红黄绿窗口按钮组的位置。侧栏折叠后宽度为 72px，当前按钮组从 `x = 24` 开始绘制，横向占用会越过侧栏右边界，挤入顶部工具栏的“展开侧栏”按钮区域。现有样式只为按钮组增加了纵向安全区，没有约束横向边界。

## 目标

- 侧栏折叠时，红黄绿窗口按钮完整落在 72px 侧栏内。
- 窗口按钮组与右侧“展开侧栏”按钮保持清晰间隔，不重叠、不贴边。
- 保持现有 72px 折叠宽度、1100px 最小窗口和展开侧栏布局不变。
- 保持 macOS 原生窗口按钮可见、可用，不用 Web 元素仿制或隐藏。

## 方案

将 `desktop/main.cjs` 中 macOS `trafficLightPosition.x` 从 24 调整为 12，保留当前纵向位置。按钮组由此整体左移，完整收纳于折叠侧栏的横向安全区内。

不增加动态 IPC，也不根据侧栏状态反复移动原生按钮。固定位置同时适用于展开态和折叠态，避免状态同步与窗口重绘复杂度。

## 测试

1. 先更新桌面壳静态测试，使其要求新的安全位置，并确认测试在生产代码修改前失败。
2. 修改 Electron 窗口配置后运行定向测试，确认回归测试通过。
3. 运行 `npm run verify:ui`。
4. 在桌面端折叠/展开侧栏，检查窗口按钮完整、与折叠按钮分离，并确认 1100px 最小窗口未出现新的裁切或重叠。

## 非目标

- 不改变 Windows/Linux 标题栏行为。
- 不调整侧栏导航、菜单间距或页面内容布局。
- 不替换 macOS 原生窗口按钮。
