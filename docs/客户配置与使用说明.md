# 客户配置与使用说明

本文档给实施人员、运营人员和客户管理员使用，目标是让新站点可以按步骤完成配置，并理解每个功能栏目怎么用。

重要原则：

- 不要把真实密码、Application Password、API Key、SFTP 密码写进文档、聊天记录或截图里。
- WordPress Application Password 不是 WordPress 登录密码，只用于本工具访问 WordPress REST API。
- 第一次配置建议先用一个测试产品、测试图片或草稿文章验证，确认无误后再批量处理。
- 涉及“同步上线”“发布”“直接替换原图”的操作，必须先审核预览内容。

## 一、首次配置前准备

请先准备以下权限和资料：

| 项目 | 用途 | 必需程度 |
| --- | --- | --- |
| WordPress 管理员账号 | 创建 Application Password、发布文章、更新媒体库 | 必需 |
| WooCommerce 管理员权限 | 创建 REST API Consumer Key / Secret、扫描产品 | 产品 SEO 必需 |
| 主机 SFTP 权限 | 直接替换媒体文件、备份和回滚图片 | 媒体库压缩建议配置 |
| Cloudflare 管理权限 | WordPress REST 被 Cloudflare 拦截时配置绕过规则 | 有 Cloudflare 时可能需要 |
| Gemini API Key 或 Vertex AI | 生成标题、描述、正文、SEO 信息 | AI 功能必需 |
| 公司资料、产品资料、关键词表 | 让 AI 输出更符合客户业务 | 强烈建议 |

## 二、第一次打开应用

首次打开应用时，如果配置不完整，会进入“连接你的站点”页面。

推荐流程：

1. 先填写 AI 配置。
2. 填写 WordPress URL、用户名、Application Password。
3. 如果需要产品 SEO，填写 WooCommerce Consumer Key 和 Consumer Secret。
4. 如果需要媒体库原图压缩或直接替换，填写 SFTP。
5. 上传客户知识库资料。
6. 点击“保存并检查”。
7. 检查左侧状态都通过后，点击“进入工作台”。

“进入未配置模式”只适合临时查看界面，不能正常同步 WordPress、生成 AI 内容或扫描产品。

## 三、创建 WordPress Application Password

Application Password 用来让工具安全调用 WordPress REST API。它不是登录后台的密码。

操作步骤：

1. 登录 WordPress 后台。
2. 打开“用户”。
3. 点击要用于本工具的用户账号，进入“个人资料”页面。
4. 找到“Application Passwords”或“应用程序密码”区域。
5. 在名称里填写一个容易识别的名称，例如 `SEO WP Sync`。
6. 点击“Add New Application Password”或“添加新的应用程序密码”。
7. WordPress 会生成一串分组显示的密码，只显示一次。
8. 立即复制这串密码。
9. 回到本工具，在“Application Password”字段粘贴。
10. 保存配置。

建议使用权限足够但不共用的后台用户。这个用户至少需要能读取和更新媒体、文章、页面、产品相关内容。

如果后台看不到 Application Passwords：

- 确认站点使用 HTTPS。
- 确认 WordPress 版本支持 Application Passwords。
- 检查安全插件是否禁用了 Application Passwords。
- 检查当前用户是否有足够权限。

## 四、系统配置字段说明

系统配置入口在左侧底部“设置”按钮，也可以在顶部工具栏点击齿轮图标。

### 1. 外观

用于切换界面主题：

- 跟随系统
- 浅色
- 深色

只影响本机界面显示，不影响 WordPress 内容。

### 2. 公司与站点

一个 APP 默认服务一个公司。公司与站点用于维护公司名称，并隔离该公司旗下不同网站的 WordPress、WooCommerce、知识库、关键词、密钥引用、模板和公司 Skills。

常用操作：

1. 填写公司名称。
2. 为当前网站填写站点名称、网站地址、WordPress 和 WooCommerce 配置。
3. 点击“保存当前站点”。
4. 如果同一个公司有多个网站，点击“新增站点”并为新网站单独配置。
5. 后续切换网站时，从左下角“当前站点”下拉框选择。

注意：

- 切换站点后，应用会刷新对应配置、关键词、知识库、模板和 Skills。
- 不同公司的站点不要混在同一个 APP 安装里。

### 3. 错误记录

系统配置里有“错误记录”面板，用来查看最近接口、配置、同步和发布失败的历史。

每条记录会显示：

- 报错时间。
- 当时操作或接口位置。
- 原始错误信息。
- 可能原因。
- 处理建议。

常见分类包括：

- WordPress 配置不完整。
- WordPress 认证失败。
- Cloudflare 或安全插件拦截 WordPress REST。
- WooCommerce API 配置异常。
- SFTP 连接或路径异常。
- AI 配置或额度异常。
- 后端或网络不可达。
- 请求超时。
- SEO 插件写入方式未确认。

使用建议：

1. 出现同步、发布、扫描或 AI 生成失败时，先打开“设置”。
2. 查看“错误记录”里最新一条。
3. 按“可能原因”和“处理建议”排查。
4. 处理完成后可以点击“清空记录”，保留新的排查记录。
5. 如果需要技术人员协助，只复制错误信息和发生步骤，不要复制任何密钥。

### 4. AI 配置

AI Provider 有两种：

| 选项 | 适合场景 | 需要填写 |
| --- | --- | --- |
| Gemini API Key | 简单部署、个人或小团队使用 | Google API Key |
| Google Cloud Vertex AI | 企业部署、服务账号管理、服务器环境 | Project ID、Location、Service Account JSON 路径 |

Gemini API Key 配置：

1. AI Provider 选择 `Gemini API Key`。
2. 在 `Google API Key` 填入 API Key。
3. 点击“测试 AI 连接”。

Vertex AI 配置：

1. AI Provider 选择 `Google Cloud Vertex AI`。
2. 填写 `Google Cloud Project ID`。
3. 填写 `Vertex Location`，常见值是 `global` 或项目实际启用区域。
4. 填写 `Service Account JSON 路径`，例如 `/app/keys/vertex-sa.json`。
5. 确认服务器上这个 JSON 文件真实存在。
6. 点击“测试 AI 连接”。

如果提示 `Vertex JSON 未找到`，说明路径填错、文件未上传到服务器，或服务器没有读取权限。

### 5. WordPress 站点配置

| 字段 | 填写方式 |
| --- | --- |
| WordPress 网址 | 填站点根域名，例如 `https://example.com`，不要填 `/wp-admin` |
| WP 用户名 | 创建 Application Password 的 WordPress 用户名 |
| Application Password | WordPress 生成的一次性应用密码 |
| Cloudflare REST Header Name | 可选，默认可用 `X-LensCraft-REST-Token` |
| Cloudflare REST Header Value | 可选，自己生成的长随机密钥 |
| WooCommerce Consumer Key | 产品 SEO 需要，通常以 `ck_` 开头 |
| WooCommerce Consumer Secret | 产品 SEO 需要，通常以 `cs_` 开头 |

保存后，密钥类字段如果显示“已保存，留空表示不修改”，说明后端已经保存密钥。以后不需要重复填写，只有要替换密钥时才输入新值。

### 6. Cloudflare REST Header

只有当 WordPress REST API 被 Cloudflare 拦截时才需要配置。常见表现：

- 发布或同步时返回 403。
- 请求被 Cloudflare challenge。
- 浏览器能打开后台，但工具无法访问 `/wp-json/`。

推荐配置方式：

1. 生成一个长随机字符串作为密钥。
2. 在本工具系统配置中填写：
   - `Cloudflare REST Header Name`: `X-LensCraft-REST-Token`
   - `Cloudflare REST Header Value`: 你的随机密钥
3. 打开 Cloudflare 控制台。
4. 进入对应站点的 WAF 规则。
5. 新建 Custom Rule。
6. 匹配条件设置为：
   - 请求路径以 `/wp-json/` 开头。
   - 请求 Header `x-lenscraft-rest-token` 等于同一个随机密钥。
7. 动作选择 Skip / Bypass。
8. 跳过会阻断 REST 的功能，例如 Managed Rules、Super Bot Fight Mode、Browser Integrity Check、Security Level、Rate Limiting。
9. 保存规则后，回到工具重新保存并检查。

注意：

- Header Value 不能公开。
- 不建议使用固定 IP 白名单，因为客户电脑或服务器 IP 可能变化。
- 如果没有 Cloudflare 拦截，可以不填写这两个字段。

### 7. WooCommerce Consumer Key / Secret

产品 SEO、产品扫描和产品同步需要 WooCommerce REST API。

创建步骤：

1. 登录 WordPress 后台。
2. 打开 `WooCommerce`。
3. 进入 `Settings`。
4. 打开 `Advanced`。
5. 打开 `REST API`。
6. 点击 `Add key`。
7. Description 可填写 `SEO WP Sync`。
8. User 选择有产品管理权限的用户。
9. Permissions 选择 `Read/Write`。
10. 生成后复制：
    - Consumer Key，填入 `WooCommerce Consumer Key`。
    - Consumer Secret，填入 `WooCommerce Consumer Secret`。

如果只给 `Read` 权限，通常只能扫描，不能同步修改产品字段。

### 8. 自动扫描产品缓存

这个设置用于后台自动刷新过期 WooCommerce 产品扫描缓存。

字段说明：

- “后台自动刷新过期 WooCommerce 产品扫描缓存”：开启后自动检查产品缓存是否过期。
- “超过多少天自动扫描”：缓存超过这个天数后触发刷新。
- “检查间隔（分钟）”：后台多久检查一次。

建议：

- 产品数量少的站点，可以开启。
- 产品数量很大的站点，先手动扫描确认稳定，再开启自动扫描。
- 如果服务器资源紧张，检查间隔不要设置太短。

### 9. SFTP 服务器配置

SFTP 主要用于媒体库原图替换、远程备份和回滚。

| 字段 | 示例 |
| --- | --- |
| SFTP 主机地址 | `sftp.example.com` 或服务器 IP |
| 端口 | 通常是 `22` |
| SFTP 用户名 | 主机面板提供的用户名 |
| SFTP 密码 | 主机面板提供的密码 |
| WordPress 根目录远程路径 | `/home/master/applications/site/public_html` |

Cloudways 常见路径格式：

```text
/home/master/applications/<app_id>/public_html
```

其他主机请向主机服务商确认 WordPress 安装根目录。这个目录下通常能看到 `wp-content`、`wp-admin`、`wp-includes`。

### 10. 知识库

知识库用于让 AI 理解客户公司、产品、关键词和写作要求。

支持上传：

- `.md`
- `.markdown`
- `.txt`
- `.csv`
- `.html`
- `.htm`

建议准备的资料：

- 公司介绍、工厂能力、证书、服务范围。
- 产品目录、规格表、型号说明。
- 核心关键词、长尾关键词、禁用词。
- 过往高质量文章、页面文案、品牌语气要求。

不要上传无关的客户隐私资料、合同、付款信息或个人联系方式。

### 11. SEO 插件检测

系统支持检测常见 SEO 插件写入方式：

- AIOSEO
- Rank Math
- Yoast
- 自定义 meta key

操作步骤：

1. 先保存 WordPress 配置。
2. 在首次配置页点击“检测 SEO 插件”。
3. 查看检测结果。
4. 如果显示可写，说明工具可以同步 SEO Title 和 Meta Description。
5. 如果显示需要补插件或 meta key，需要让实施人员处理。

## 五、左侧栏目怎么用

### 1. 中控台

中控台用于总览站点 SEO 状态、任务队列和优先处理项。

常用流程：

1. 进入“中控台”。
2. 查看系统状态、紧急问题、警告问题、已生成未同步数量。
3. 在“优先处理队列”里按类型、分组或问题筛选。
4. 点击问题对应的操作按钮，跳转到具体工作台处理。
5. 在每日 SEO 队列里查看待生成、运行中、失败和已完成任务。

适合每天开始工作时先看一遍。

### 2. 站点资料库

这个栏目用于维护当前站点资料库，并把公司事实、产品 / SKU、关键词、证书边界和写作规则整理成 AI 可复用的公司 Skills。

常用流程：

1. 确认左下角已经选择正确站点。
2. 上传或维护三类资料：
   - 公司信息：品牌、工厂、证书、服务、语气。
   - 产品 / SKU 信息：产品线、SKU、型号、规格、卖点、适用场景。
   - 产品关键词：核心词、长尾词、禁用词、页面词库。
3. 资料已经整理好的，选择“直接归档”；资料很散的，选择“上传并用 AI 整理”。
4. 在“公司 Skills”里检查 Company Skill、Product & SKU Skill、Keyword Skill 和 Task Skill。
5. 发布公司 Skills 后，后续博客、产品 SEO、页面计划、图片 SEO 会按这个公司的写法和 SKU 规则生成内容。

建议先把客户资料补齐，再批量生成内容。否则 AI 输出会更泛。

### 3. SEO Audit

SEO Audit 用于导入外部审计结果，并把审计问题转成可执行任务。

常用流程：

1. 上传 SEO Audit 文件。
2. 先预览导入结果。
3. 确认任务数量、任务类型和优先级。
4. 导入任务。
5. 按状态、任务类型、优先级或关键词筛选。
6. 对可生成的任务点击生成。
7. 检查生成结果，包括 SEO Title、Meta Description、内容块、FAQ、内链建议。
8. 审核后再复制到 WordPress 或转交页面制作人员。

任务类型包括：

- 产品页扩写
- 分类集合页
- 信任页补强
- 新页面规划
- Blog 翻新
- 标签页处理
- Meta 修复

### 4. 图片与媒体 SEO

这个栏目有两个子页：“图片处理”和“媒体库SEO压缩”。

#### 图片处理

用于本地上传新图片，压缩成 WebP，生成图片 SEO 信息，并上传到 WordPress。

常用流程：

1. 上传图片，或把图片拖进页面。
2. 选择目标宽度：
   - 原尺寸：保持原图宽度。
   - 1200px：Banner / 大图。
   - 800px：详情页主图。
   - 600px：内容配图。
   - 450px：缩略图 / 列表。
3. 设置质量。
4. 填写主关键词。
5. 补充图片用途或额外描述。
6. 点击处理当前图。
7. 检查压缩前后预览、文件名、Title、Alt、Caption、Description。
8. 确认无误后上传到 WordPress。

使用建议：

- Alt Text 要描述图片真实内容，不要堆关键词。
- 文件名建议英文、小写、短横线分隔。
- 产品图优先保留清晰细节，不要盲目压太小。

#### 媒体库SEO压缩

用于扫描 WordPress 已有媒体库，批量补 SEO 字段、压缩图片并同步。

标准流程：

1. 点击“扫描媒体库”。
2. 等待媒体列表加载完成。
3. 可按“问题筛选”查看缺 Title、缺 Alt、缺 Description 等问题。
4. 可上传关键词表，让 AI 参考关键词。
5. 勾选要处理的 SEO 字段，例如 Filename、Title、Alternative Text、Caption、Description。
6. 填写“批量核心关键词”。
7. 勾选要处理的图片。
8. 先点击“AI 生成预览”。
9. 在“SEO 审核”区域逐条检查和修改。
10. 审核通过后再选择：
    - “批准并同步到 WordPress”：审核后同步。
    - “仅更新 SEO”：只把已有 SEO 元数据推送到 WordPress。
    - “直接同步上线”：生成并替换文件或同步字段。

如果 WooCommerce 或其他后台任务正在运行，媒体扫描会显示“排队中”；前一个任务结束后会自动开始。排队期间可点击“取消排队”。

关于“免SFTP模式”：

- 开启后会尝试通过 REST 插件接口替换原图。
- 如果插件不可用但 SFTP 已配置，会自动回退到 SFTP。
- 如果既没有可用插件也没有 SFTP，不要直接替换原图。

建议：

- 批量上线前先选 3 到 5 张图片测试。
- 图片替换类操作尽量在访问低峰期执行。
- 执行后检查前台图片显示、媒体库字段和缓存。

### 5. 博客撰写与修改

这个栏目有三个子页：“博客写作”“展会/证书/项目blog”“批量修复Blog格式”。

#### 博客写作

用于生成普通博客、重写旧文章、优化终稿并同步 WordPress。

新写博客流程：

1. 填写博客主题。
2. 填写关键词。
3. 可上传 Excel / CSV 关键词表。
4. 可粘贴参考内容。
5. 点击“生成大纲”。
6. 人工修改大纲。
7. 点击“批准并撰写全文”。
8. 在正文编辑区人工检查和修改。
9. 点击“生成 SEO 信息”。
10. 检查 SEO Title 和 Meta Description 长度。
11. 点击“自动内链 + 排版”生成发布前预览。
12. 选择“同步为草稿”或“确认发布”。

重写旧文章流程：

1. 输入旧文章 URL 并点击“抓取内容”，或手动粘贴原文。
2. 填写重写要求，例如“语气更专业、增加采购场景、加入 SEO 优化”。
3. 点击“开始重写”。
4. 检查正文、SEO 信息和预览。
5. 同步为草稿，人工二次检查后发布。

终稿优化流程：

1. 上传业务人员改完的 Word、Markdown、HTML 或 TXT。
2. 系统读取正文并自动优化。
3. 检查内链、目录、CTA 和预览。
4. 如果要覆盖编辑区，点击“使用优化稿覆盖编辑区”。
5. 同步为草稿或确认发布。

#### 展会/证书/项目blog

用于生成固定类型的业务 Blog。

支持类型：

- 展会复盘 Blog
- 证书/认证 Blog
- 工程项目 Blog
- 产品视频 Blog

常用流程：

1. 选择文章类型。
2. 填写主题、目标关键词和对应业务字段。
3. 添加图片：
   - 上传本地图片。
   - 从媒体库已扫描图片中选择。
4. 生成大纲。
5. 检查并修改大纲。
6. 生成完整 Blog。
7. 检查预览、图片、SEO 标题和描述。
8. 创建 WordPress 草稿，或导出 Word 文档给业务审核。

建议每篇文章至少检查事实信息，例如展会名称、证书编号、项目地点、产品型号和视频链接。

#### 批量修复Blog格式

用于扫描已有 WordPress Blog，批量修复排版、SEO、Tags、Schema 或薄内容问题。

常用流程：

1. 选择 Blog 类型。
2. 选择修复模式。
3. 可按问题类型过滤。
4. 点击“扫描 Blog”。
5. 打开单篇详情查看问题。
6. 先生成预览，不要直接应用。
7. 检查格式、SEO 标题、Meta Description、Tags、FAQ Schema、Article / Video Schema。
8. 确认后再应用到 WordPress。

建议：

- 批量应用前先处理 1 到 3 篇测试文章。
- 对正文偏薄的文章，需要人工确认新增内容是否真实。
- 如果文章涉及证书、项目、展会事实，必须人工复核。

### 6. 页面计划

页面计划用于生成 Elementor 页面制作 brief、页面 SEO 结构和内链建议。

常用流程：

1. 进入“页面计划”。
2. 输入关键词、目标分类、目标市场或页面要求。
3. 选择是否使用客户资料上下文。
4. 启动生成任务。
5. 等待任务完成。
6. 检查每个页面计划：
   - Page Title
   - SEO Title
   - Meta Description
   - Slug
   - Primary Keyword
   - Secondary Keywords
   - H1 / H2 / H3 结构
   - FAQ
   - CTA
   - 图片建议和 Alt Text
   - 内链建议
7. 导出 Markdown、CSV 或 Elementor brief HTML。
8. 交给页面制作人员在 Elementor 里搭建。

页面制作前要确认：

- 一个页面只有一个 H1。
- H2 结构能覆盖采购者关心的问题。
- 图片建议和实际图片一致。
- 内链指向真实存在或计划创建的页面。
- Meta Description 不能过长。

### 7. WooCommerce

WooCommerce 栏目用于扫描产品、生成产品 SEO 字段，并同步回 WordPress。

标准流程：

1. 点击“扫描产品”。
2. 等待产品列表加载。
3. 可按产品名称搜索。
4. 可按分类筛选。
5. 可按问题筛选，例如 Description 为空、Short Description 为空、Meta Description 默认或未写。
6. 勾选要生成或同步的字段：
   - Short Description
   - Description
   - ACF Extra Info
   - AIOSEO Title
   - AIOSEO Description
   - Tags
7. 填写“批量核心关键词”。
8. 勾选产品。
9. 点击“AI生成所选字段”。
10. 打开“审核并发布”。
11. 在审核区逐条修改。
12. 选择“仅批准”或“批准并同步到 WordPress”。

如果媒体扫描或优化任务正在运行，产品扫描会进入后台队列并显示前方任务数量，无需等待后再次点击。

如果要直接同步列表中选中的产品：

1. 确认已选择产品。
2. 确认字段已生成并审核。
3. 点击“同步所选到WordPress”。
4. 到 WordPress 前台检查产品页。

产品详情里的常见操作：

- 查看原文内容预览。
- 单独生成某个字段。
- 上传参考图或选择媒体库图片。
- 编辑 SEO Core Keywords。
- 查看和选择历史 Tags。

建议：

- 产品详情页 Description 涉及规格、材料、安装和采购信息，必须人工复核。
- Tags 不要生成过多，保持可管理。
- AIOSEO Title 建议控制在 60 字符以内。
- AIOSEO Description 建议控制在 160 字符以内。

## 七、常见问题处理

### 1. 提示 WordPress 网址、用户名和应用密码未配置

处理方式：

1. 打开系统配置。
2. 确认 WordPress URL 使用 `https://`。
3. 确认 WP 用户名正确。
4. 确认 Application Password 已填写或显示已保存。
5. 保存配置后重试。

### 2. WordPress 返回 401 或认证失败

常见原因：

- 用户名填错。
- Application Password 复制不完整。
- 把 WordPress 登录密码当成 Application Password。
- 该用户权限不足。
- 安全插件阻止 Application Password。

处理方式：

1. 删除旧 Application Password。
2. 在 WordPress 后台重新生成一个。
3. 粘贴到工具里并保存。
4. 重试。

### 3. WordPress 返回 403 或被 Cloudflare 拦截

处理方式：

1. 按本文“Cloudflare REST Header”配置 Header。
2. 确认 Cloudflare 规则只对 `/wp-json/` 生效。
3. 确认 Header Name 和 Header Value 与工具配置一致。
4. 保存后重新检查。

### 4. WooCommerce 扫描不到产品

常见原因：

- Consumer Key / Secret 错误。
- WooCommerce Key 只有 Read 权限或权限不足。
- 站点没有安装或启用 WooCommerce。
- REST API 被安全插件或 Cloudflare 拦截。

处理方式：

1. 重新创建 WooCommerce REST API Key。
2. Permissions 选择 `Read/Write`。
3. 保存配置。
4. 重新扫描产品。

### 5. AI 连接失败

Gemini 常见原因：

- API Key 填错。
- Key 没有权限。
- 网络或服务端无法访问 API。

Vertex 常见原因：

- Project ID 错。
- Location 错。
- Service Account JSON 路径错。
- 服务器没有挂载 JSON 文件。
- 服务账号没有 Vertex AI 权限。

处理方式：

1. 检查 AI Provider 是否选对。
2. 重新保存配置。
3. 点击“测试 AI 连接”。
4. 如果仍失败，交给技术人员检查服务器日志。

### 6. SFTP 连接失败

常见原因：

- Host、Port、User、Password 填错。
- 主机限制了来源 IP。
- WordPress 根目录路径填错。
- SFTP 用户没有写入权限。

处理方式：

1. 用主机面板确认 SFTP 信息。
2. 确认远程根目录下能看到 `wp-content`。
3. 确认 SFTP 用户可以写入 uploads 目录。
4. 保存后重试。

### 7. 保存后密钥输入框变空

这是正常现象。系统不会把密钥明文回显到前端。

如果字段提示“已保存，留空表示不修改”，说明密钥已经保存。只有需要替换密钥时，才输入新值并保存。

### 8. 媒体库替换后前台图片没变化

常见原因：

- WordPress 缓存。
- Cloudflare 缓存。
- 浏览器缓存。
- 图片 CDN 缓存。

处理方式：

1. 清理 WordPress 缓存插件。
2. 清理主机缓存，例如 Cloudways Varnish。
3. 清理 Cloudflare 缓存。
4. 用无痕窗口或带时间戳的图片 URL 检查。

### 9. SEO 插件检测不到或不可写

处理方式：

1. 确认站点安装了 AIOSEO、Rank Math 或 Yoast。
2. 确认插件已启用。
3. 保存 WordPress 凭据后重新检测。
4. 如果仍不可写，让实施人员确认 meta key 或安装配套连接插件。

## 九、给客户的安全提醒

请向客户明确：

- 不要把 Application Password 发到微信群、邮件正文或未加密文档里。
- 不要把 WooCommerce Consumer Secret 或 Google API Key 截图外传。
- 离职人员使用过的 WordPress 用户，应删除或重置 Application Password。
- 如果怀疑密钥泄露，应立即删除旧密钥并重新生成。
- 批量发布前必须人工审核，不要把 AI 内容直接无审查上线。
